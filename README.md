# Personal Portfolio

A responsive multi-page personal portfolio website built with HTML and CSS.

This project is part of the [Personal Portfolio project on roadmap.sh](https://roadmap.sh/projects/portfolio-website). I converted my previous HTML-only website into a personal portfolio and used CSS to improve its layout, styling, and responsiveness.

## Pages

- Home
- About
- Projects
- Articles
- Contact

## Features

- Zen, minimalist design: washi-paper tones, ink typography, and accents from the Tinapay logo
- Scroll animations: text reveals, words that fill with ink, a self-drawing timeline, and a pinned horizontal project gallery
- Hand-drawn ensō circle around the hero portrait
- Hide-on-scroll navigation with a full-screen mobile menu
- Soft page transitions and a reduced-motion fallback
- Responsive layout for desktop and mobile screens
- Styled contact form
- Personal information, education, and work experience
- Project links
- Semantic HTML structure

## Built With

- HTML5
- CSS3
- Vanilla JavaScript (no libraries)
- Git and GitHub

## What I Practiced

- Using Flexbox for layouts and navigation
- Creating responsive designs with media queries
- Styling forms, cards, links, and buttons
- Using CSS variables for reusable colors
- Organizing a multi-page website
- Publishing a project using GitHub
